# 📚 | Présentation

> Le **All Star UHC** est un mode de jeu réunissant plusieurs univers dans un seul mode de jeu, il est dans sa construction inspiré de la version des streamers **Nardcoo** et **Nannoxx** ([Redirection](https://docs.as-uhc.fr/)) mais de nouveaux rôles ont été ajouté, les rôles avec le "**- AS**" signifie qu'il s'agit des mêmes rôles (_ou fortement inspiré_) de la version java.

***

Une **partie** est alors divisé en plusieurs segments nommé **épisode** durant chacun **10 minutes** est divisé en un **cycle** jour/nuit durant **5 minutes** chacun.&#x20;

{% hint style="info" %}
À l'instar de la version java, il existe **3 camps** principaux :&#x20;

* Les <mark style="color:green;">**Protagonistes**</mark>.
* Les <mark style="color:red;">**Antagonistes**</mark>.
* Les <mark style="color:yellow;">**Divergents**</mark>

Ils existent également des rôles <mark style="color:orange;">**Solitaire**</mark>, <mark style="color:purple;">**Duo**</mark> ou <mark style="color:blue;">**Trio**</mark> qui doivent gagner entre eux en fonction des conditions imposées.
{% endhint %}
